# Trioty Restaurant releases

Public distribution of Trioty Restaurant desktop and Hub installers. Application source remains in the private development repository.

See [Releases](https://github.com/trioty/trioty-restaurant-releases/releases) for published Mac and Windows installers. Testing releases contain the complete desktop, local service and restaurant interface. Initial installation requires administrator access; subsequent configured updates preserve restaurant data and run outside service hours.

Installed testing builds verify signed manifests using the dedicated testing public key. Stable builds use a separate trust configuration.
